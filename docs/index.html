About this dashboard

The page is static and free to host. The collector checks Dialectica’s public top 100 about every 15 minutes, then saves the historical snapshots in the public data file. GitHub’s scheduled runs can occasionally start late. The reload button only reloads this saved file; it does not start an extra source fetch.

The full saved snapshot history is available as JSON. Only the display labels and public leaderboard measurements are included; private matching identifiers are not published.
